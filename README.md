# AWS Serverless Terraform Platform

This repository is a hands-on AWS Cloud Engineering project focused on building a serverless platform using Terraform, AWS Lambda, API Gateway, DynamoDB, IAM, CloudWatch, Bash scripts, and GitHub Actions.

## Purpose

The goal of this project is to practice Terraform through a real-world AWS architecture while preparing for the HashiCorp Terraform Associate certification and building a professional portfolio project for CloudOps / DevOps / AWS Cloud Engineer roles.

## Target Architecture

API Gateway → Lambda → DynamoDB → CloudWatch

## Current Stage

Version 0 - Repository setup and Terraform basic workflow.

## Main Skills Practiced

- Terraform workflow: init, fmt, validate, plan, apply, destroy
- AWS provider configuration
- Variables, outputs and state
- IAM roles and least privilege
- Serverless infrastructure
- Bash automation
- GitHub Actions CI/CD
- CloudWatch observability
